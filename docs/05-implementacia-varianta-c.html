function ProjectTile({ proj, index, sizes }: {
  proj: Project; index: number; sizes: string;
}) {
  // Chýbajúce hodnoty vypadnú aj s oddeľovačom — preto .filter()

    proj.budgetString,
    proj.duration,

  return (
    <Link
      href={`/portfolio/${proj.id}`}
      className={`group/tile relative block transition-[transform,box-shadow] duration-500 ${EASE}
        hover:-translate-y-1 hover:shadow-[0_22px_52px_rgba(0,0,0,0.19)]

Krok 07Čo sa nemení

  1. Filtračné čipy — kategórie aj lokality, vrátane compactFilters na domovskej stránke.
  2. Hlavička sekcie, odkaz „Všetky projekty“ a prázdny stav pri kategórii bez projektov.
  3. Logika filtrovania, onlyIds, locationFilter aj defaultCategory.
  4. Funkcie scrollLeft a scrollRight — posúvajú o clientWidth, čo pri náhľade funguje správne.
  5. Dáta projektov. Žiadna zmena v src/data/projects.ts.

Krok 08Kontrola pred odovzdaním

  • Na domovskej stránke vidno tri celé dlaždice a kúsok štvrtej.
  • Ľavá šípka je na začiatku neaktívna, pravá na konci radu tiež.
  • Po filtrovaní na kategóriu sa stav šípok prepočíta a rad skočí na začiatok.
  • Dlaždice projektov bez rozpočtu a trvania majú rovnakú výšku ako ostatné (napr. „Hrubá stavba Dúbravy“).
  • Riadok údajov na takej dlaždici končí rokom a nemá visiaci oddeľovač ·.
  • Pri prejdení myšou: fotka sa priblíži, dlaždica sa nadvihne, linka pri čísle sa predĺži, vysunie sa „Zobraziť“.
  • Na /portfólio vyzerá dlaždica identicky ako na domovskej stránke.
  • Na mobile je jedna dlaždica na šírku 86 % a posúvanie prstom funguje so zarážkami.
  • Pri zapnutom obmedzení pohybu v systéme sa nič nehýbe.
  • npm run build prejde — po zmazaní ProjectMeta nesmú zostať nepoužité importy.
